# Pillar 1: User

Continuously authenticate, assess, and monitor user activity to govern
access to data, applications, assets, and services.

## Key principles

- Identity is the new perimeter — every request is authenticated regardless of network location.
- Authentication is continuous and risk-adaptive, not a one-time login event.
- Least-privilege access is enforced per session, not granted broadly at account creation.

## Maturity snapshot

| Stage | Characteristics |
|---|---|
| Traditional | Passwords, static roles, one-time login trust for the session duration |
| Advanced | Phishing-resistant MFA, federated SSO, conditional access policies |
| Optimal | Continuous, behavior-based authentication; just-in-time, attribute-based access |
