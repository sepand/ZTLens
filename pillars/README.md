# The 7 Pillars of Zero Trust (DoD ZT RA 2.0)

DoD ZT RA 2.0 organizes Zero Trust into seven interlocking pillars. No pillar
stands alone — maturity in one (e.g., User) is only as effective as the
telemetry and enforcement it can draw from and push to the others (e.g.,
Visibility & Analytics, Automation & Orchestration).
